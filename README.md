# gamble

가상 칩으로 즐기는 한 파일짜리 게임룸이에요. 블랙잭, 바카라, 홀짝, 그래프(크래시), 마인, 플링코를 칩 지갑 하나로 오가며 플레이해요.

## 게임

| 게임 | 규칙 | 배당 | 환수율 |
|---|---|---|---|
| 블랙잭 | 6덱, 딜러는 모든 17에서 멈춤, 더블·스플릿(4패까지), 딜러 피크 | 블랙잭 3:2, 승 1:1 | 약 99.5%(기본 전략 기준) |
| 바카라 | 8덱 푼토 방코, 표준 세 번째 카드 규칙 | 플레이어 1:1, 뱅커 0.95:1, 타이 8:1 | 뱅커 98.9%, 플레이어 98.8%, 타이 85.6% |
| 홀짝 | 바둑통 속 돌 1~20개의 홀짝 맞히기 | 1.95배 | 97.5% |
| 그래프 | 배수가 오르다 무작위로 터짐, 그 전에 캐시아웃 | 캐시아웃 배수 | 99% |
| 마인 | 5×5 칸, 지뢰 1~24개 | 연 칸 수에 따라 상승 | 99% |
| 플링코 | 핀 12줄, 위험도 3단계 | 칸 배수 0.2~170배 | 99.0~99.1% |

받을 칩에서 1개 미만은 버려요. 판이 끝나기 전에 새로고침하면 그 판에 건 칩은 돌려받아요.

## 가상 칩만 쓰는 이유

칩은 돈으로 사거나 팔 수 없고, 다른 서비스의 포인트·시드와 바꾸거나 연동하지 않아요. 우연으로 승패가 갈리는 게임에서 칩이 재산 가치와 이어지면 도박·도박장 개설(형법 제246조·제247조), 게임 결과물 환전(게임산업진흥에 관한 법률 제32조 제1항 제7호) 규제를 받을 수 있어요. 그래서 칩과 결과를 기기 밖으로 보내는 코드도 넣지 않았고, 시험이 이를 검사해요.

## 저장

칩과 기록은 그 브라우저의 localStorage(`gamble-v1`)에만 저장돼요. 기기끼리 공유되지 않고, 브라우저 데이터를 지우면 처음부터 시작해요. 칩이 10개보다 적어지면 1,000개를 다시 받을 수 있어요.

## 웹주소로 사용하기 (GitHub Pages)

main에 반영되면 GitHub Actions가 전체 시험을 통과한 `index.html`만 배포해요.

처음 한 번: 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 고른 뒤, **Actions → Test and deploy GitHub Pages → Run workflow**를 main에서 실행해요. 앱 주소는 `https://<계정>.github.io/gamble/`예요.

## 개발 시험

```sh
npm ci
npx playwright install chromium
npm test
```

`tests/sandbox.html`의 보안 iframe에서 폭 320·360·390·430px, 라이트·다크로 실행해요. 시험은 `window.__GAMBLE_TEST`로 카드 순서·배수·지뢰 위치 같은 결과를 고정해요. 시스템 Chromium은 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정할 수 있어요.

작업 규칙은 [AGENTS.md](AGENTS.md)에 있어요.
